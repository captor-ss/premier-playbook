## Files
- `results.csv`: every match (stage, score, MVP)
- `standings.csv`: final regular-season seeding
- `box_scores.csv`: per-pilot kills, deaths, assists and minutes for each match
- `kill_feed.csv`: every logged kill with its second in the match
- `players_regular_season.csv`, `players_playoffs.csv`: pilot totals
- `season1_full_data.json`: the full site data file at the end of Season One (league and prac data)
- `prac_snapshot.json`: prac games collected up to the end of Season One
